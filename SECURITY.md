# Security

Porchlight stores residents' contact details and an association's financial records, so
security reports are taken seriously.

## Reporting a problem

Please **don't open a public issue**. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/tachyonFlux/porchlight-hoa/security/advisories/new).

Include what an attacker could do, the steps to reproduce it, and the version you tested. You
should hear back within a week. Fixes are released as a new patch version, and the release
notes credit you unless you'd rather not be named.

## Supported versions

Only the latest minor release gets security fixes. Upgrading is described in the
[README](README.md#upgrading).

## Running it safely

The README's security notes cover the most important points: use HTTPS, keep the data folder
on a local volume with regular backups, set the number of trusted proxies correctly, and
turn on two-step sign-in for board members.
